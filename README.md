# Simulador Estatístico de Lançamento de Dados 🎲

Este projeto é uma aplicação de console desenvolvida em linguagem C que realiza simulações matemáticas e probabilísticas. O programa simula 1.000 lançamentos consecutivos de um dado clássico de seis faces, calcula a frequência absoluta de cada face e exibe a distribuição percentual estatística dos resultados.

###  Tecnologias Utilizadas
- Linguagem C puro (Padrão ANSI)
- Biblioteca `time.h` (Utilizada para aleatoriedade randômica real baseada no clock do sistema)
- Vetores e Estruturas de Repetição (`for`) para otimização de memória

###  Funcionalidades
- Geração automatizada de dados pseudoaleatórios na faixa de 1 a 6.
- Armazenamento em vetores indexados para contagem precisa de ocorrências.
- Cálculo aritmético de porcentagem em tempo real e saída de dados formatada via console.
